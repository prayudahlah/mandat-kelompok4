| Teknologi | Penggunaan |
|-----------|------------|
| PostgreSQL | MDM Hub |
| SQL Server | Staging & Data Warehouse |
| Pentaho Data Integration | Pipeline ETL |
| Power BI | Dashboard & Visualisasi |
